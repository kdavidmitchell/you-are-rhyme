# You Are Rhyme - v0.1.0 (Local CPU Edition)

Welcome to the first standalone release of **You Are Rhyme**! This release packages the interactive installation into a single, easy-to-install desktop application for Windows.

### What is Included
This build features the full CPU Partner experience, allowing you to play the voice-controlled dueling engine locally against an AI opponent. 
* **Zero-Setup Architecture:** The React frontend, Node.js game server, and Python Whisper voice transcription service have all been bundled together. No terminal commands, Python environments, or Node installations are required.
* **Procedural Playworlds:** Experience Act 3, Scene 4 of *Hamlet* where the physical constraints of the scene (Hamlet, Gertrude, Polonius, and the arras) are dynamically constructed via a Genetic Algorithm.
* **Voice-Driven Mechanics:** Your vocal delivery directly dictates your in-game actions. Volume triggers Lunges/Repels, pacing shifts trigger Feints/Interposes, and dramatic pauses trigger Pierces/Solidifies.

### Installation (Windows)
1. Download `you-are-rhyme Setup 0.1.0.exe` from the Assets below.
2. Double-click the installer to install and launch the game. 

*(Note: Because this is an unsigned indie executable, Windows Defender SmartScreen might flag it as an unrecognized app. You can safely click **"More info"** -> **"Run anyway"**).*
